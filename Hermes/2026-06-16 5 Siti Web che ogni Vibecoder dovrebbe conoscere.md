## Riassunto

Il post di suraj.dsgn presenta 5 siti utili per i vibe coders, ovvero chi sviluppa usando strumenti AI. Vengono mostrati strumenti per trovare prompt pronti all'uso per creare landing page animate, componenti UI e sezioni hero. Le risorse spaziano da librerie di prompt gratuite a blog editoriali dedicati al vibe coding. L'obiettivo è aiutare i creator a costruire prodotti digitali più velocemente senza scrivere codice manualmente.

## Contenuto

Slide 1 - Titolo: '5 Websites Every Vibecoder should know!' — by suraj.dsgn

Slide 2 - Motion Sites (motionsites): Piattaforma con prompt pronti per landing page animate e sezioni hero. Slogan: 'Unlock Your AI Design Superpowers'. Mostra template come Velorah, Shamoni, Urban Jungle, Nike Premium Landing, ecc. Descrizione: 'Premium prompts built specifically for animated, motion-first hero sections.'

Slide 3 - VibeUI: Libreria di 92 prompt UI gratuiti organizzati per componente (Auth Forms, Pricing, Hero Sections, Nav Bars, ecc.) su 15 categorie. Integrato con GlowUp UI, Claude, GPT-5, Gemini. Descrizione: '92 free UI prompts organized by component. Copy, paste, ship.'

Slide 4 - Trickle Vibe Coding: Blog/prompt directory con 50 prompt organizzati per stile visivo, mood e tipo di interazione. Include categorie come Cross-media Integration, AI-generated Hero Image Page, Fullscreen Video Background. Descrizione: '50 prompts organized by visual style, mood, and interaction type.'

Slide 5 - Vibe Code Components: Libreria interattiva di componenti React con prompt pronti. Categorie: UI, Content, Micro-Interactions, Forms, Nav, Heroes, CTAs. Top prompts: Voice Typing, Slide-Over Panel, PWA Install Prompt. Descrizione: 'Premium React component prompts that generate production-ready UI.'

Slide 6 - Vibe Coder Blog: Blog editoriale definito 'the missing manual for vibe coders'. Offre tutorial, recensioni di strumenti e percorsi di apprendimento (Agency Track, Career Changer Track, Designer Track, Developer Track, ecc.). Descrizione: 'The best editorial blog for where vibe coding and AI design are heading.'
